# lor
## Student Expense Tracker

A small command-line expense tracker built with Python's standard library and SQLite.

Run it with:

```
python3 expense_tracker.py
```

Features:

- Add an expense (description, category, amount, date)
- Categorize expenses (preset categories or your own)
- View all expenses with total spending, broken down by category
- View expenses filtered by category
- Delete an expense by ID

Data is stored in `expenses.db`, created automatically in the working directory.
