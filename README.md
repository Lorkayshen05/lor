# AI Quest

A gamified learning platform for a Year 2 Computer Science / Data Analytics
student: Python → AI Agents, technical English practice, CGPA/study tracking,
and real project tracking — all wrapped in a real account system with an
XP/level/streak/achievement game layer.

## Stack

- **Next.js 15** (App Router) + **TypeScript** + **Tailwind CSS v4**
- **Drizzle ORM + @libsql/client** — SQLite locally (`local.db`), or point
  `DATABASE_URL`/`DATABASE_AUTH_TOKEN` at a [Turso](https://turso.tech) database in production
- **zod** validates every API route and server action
- **Pyodide in a Web Worker** (`public/pyworker.js`) — Python runs entirely in
  the student's browser, never on the main server. The core runtime is
  self-hosted under `public/pyodide` (regenerated by `npm install`); package
  wheels like numpy/pandas still lazy-load from jsDelivr on demand. An
  optional `PISTON_URL` lets a submission be trusted-re-run server-side
  instead of accepting the browser's result.
- **scrypt + random session tokens** (stored hashed) for auth — no bcrypt/
  next-auth dependency needed
- Optional `ANTHROPIC_API_KEY` for a live AI Tutor; without it, every tutor
  mode falls back to rule-based responses

## Getting Started

```bash
npm install            # also self-hosts the Pyodide runtime (postinstall)
npx drizzle-kit generate  # only needed after changing src/db/schema.ts
npm run db:migrate     # create the SQLite schema
npm run db:seed        # seed the 10-course path, ~26 quests, 13 achievements
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) and log in with the
pre-filled demo account (`demo@aiquest.dev` / `demo1234` — seeded as an
admin, so it can also see `/admin`).

## Verifying changes

```bash
npm run lint       # eslint
npm run typecheck  # tsc --noEmit
npm run build      # next build (also type-checks)
npm test           # node's built-in test runner via tsx, tests/**/*.test.ts
```

The test suite covers the Pyodide grading harness (loaded directly in Node
for the test run), XP/level/mastery/streak math, English-answer checking,
and the CGPA material extractor's verbatim-quote guarantee — no test
framework dependency needed.

## Project Structure

- `src/db/schema.ts` — Drizzle schema (User, Session, Course, Module, Lesson,
  Quest, Question, Submission, Progress, Achievement, UserAchievement,
  Mistake, Streak, Subject, StudyTask, Project, EnglishAttempt)
- `src/db/seed.ts` — idempotent upsert seed (safe to re-run without wiping
  user progress) from `src/content/*`
- `src/content/courses/*` — the 10-course learning path as typed data: CODE
  quests (starter code, hidden Python tests, hints) and QUIZ quests (2
  variants per slot, per-option feedback)
- `public/pyworker.js` + `src/hooks/usePyRunner.ts` — the Pyodide Web Worker
  and the client hook that runs/times out/restarts it
- `src/lib/game/*` — XP/level, mastery, streak, weak-topic, and achievement
  logic, all pure and unit-tested
- `src/lib/auth/*` — scrypt password hashing, session creation/validation,
  login/register/logout server actions
- `src/middleware.ts` — lightweight cookie-presence gate (libsql's `file:`
  driver needs Node's fs, so full session validation happens per page/route
  via `getSessionUser()`, not in Edge middleware)
- `src/app/*` — one route per page: `/`, `/login`, `/register`, `/dashboard`,
  `/courses`, `/course/[id]`, `/quest/[id]`, `/english`, `/cgpa`, `/projects`,
  `/profile`, `/leaderboard`, `/admin`
