# English Game Mode 🎮

A small English practice app for one student. Plain HTML, CSS and JavaScript — no build step, no backend.

## Six modes
Speaking · Listening · Reading · Writing · Vocabulary · Speed

## XP and levels
+10 correct · +20 skill challenge · +15 natural sentence · +15 new vocabulary

L1 0–100 · L2 101–250 · L3 251–500 · L4 501–800 · L5 801–1200 · L6 1201+

## How to run
```
python3 -m http.server 8000
```
Then open http://localhost:8000 (Chrome works best for voice).

Progress, streak and the 25-minute daily timer are saved in localStorage.
